# amateur-radio-com-exam-test

业余无线电操作技术能力验证考试 · 模拟考试程序

基于中国无线电协会公布的《业余无线电台操作技术能力验证题库》(v171031，共 1237 题、53 张附图) 构建的单文件模拟考试应用。

## 快速使用

无需安装任何依赖——直接双击打开：

```
dist/业余无线电模拟考试系统.html
```

任何现代浏览器（Windows / macOS / Linux / 手机）均可运行，所有题目、图片、程序全部内嵌在这一个文件中（约 6.7 MB），数据保存在浏览器 localStorage，完全离线使用。

## 功能

- **全真模拟考试**：按真实考试规则（国无协〔2018〕13号）随机抽题、限时、选项乱序
  - A 类：30 题 / 40 分钟 / 答对 25 题合格（题库 361 题）
  - B 类：50 题 / 60 分钟 / 答对 40 题合格（题库 685 题）
  - C 类：80 题 / 90 分钟 / 答对 60 题合格（题库 1061 题）
- **顺序练习**：按题号顺序逐题复习，即时判分并显示正确答案
- **随机练习**：随机顺序抽取 10/25/50/100/200/全部 题复习
- **错题本**：答错自动收录，支持回看（含正确答案与上次错选）、错题重考、连对 2 次自动移出、导出/导入 JSON
- **统计**：覆盖率、正确率、各类别掌握度、历史成绩单
- 考试中途刷新页面可恢复未交卷的会话

## 关于答案正确性

官方 TXT 题库格式中每题的正确答案恒为 `[A]` 选项（经抽样人工核验与官方答案一致）。本程序在展示时随机打乱选项顺序（可在设置中关闭），判定始终指向原始正确选项。

附图与题目按官方 `[P]图片文件名` 严格对应（文件名 = 题号.jpg，构建时逐一校验）；官方题库漏标的 `LK0938.jpg` 已在构建时补上关联。

## 开发

```
src/index.html      HTML 模板
src/styles.css      样式
src/app.js          前端逻辑（原生 JS，无框架、无外部依赖）
tools/build.py      构建脚本：解析 GBK 题库 → 校验 → 内嵌数据/图片 → 生成单文件 HTML
tools/e2e-test.js   Playwright 端到端冒烟测试
tools/verify-answers.js   全量答案正确性校验：与官方题库源文件逐字段比对全部 1237 题（题干/四选项/正确答案/附图/类别），零依赖、无需浏览器
database/           官方题库原始文件（勿改动）
```

重新构建：

```bash
python tools/build.py
```

运行测试（需要 playwright + chromium）：

```bash
node tools/e2e-test.js
```

无需任何依赖、不启动浏览器的全量答案正确性校验：

```bash
node tools/verify-answers.js
```

## 题库版本说明

本程序基于 v171031（2017 年版）题库。中国无线电协会已于 2025 年启用新版题库（C 类改为 90 题含多选），如需备考最新考核请以 CRAC 官方最新题库为准。
