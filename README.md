# amateur-radio-com-exam-test

业余无线电操作技术能力验证考试 · 模拟考试程序

基于中国无线电协会公布的《业余无线电台操作技术能力验证题库》构建的单文件模拟考试应用。内置 **2025 版**与 **2017 版**两套题库，任选其一双击即用。

- **2025 版**（推荐，含多选）：`dist/业余无线电模拟考试系统-2025.html`，1375 题、附图 53 张、多选 252 题（约 1.2 MB）
- **2017 版**：`dist/业余无线电模拟考试系统.html`，1237 题、附图 53 张（约 6.7 MB）

## 快速使用

无需安装任何依赖——直接双击打开：

```
dist/业余无线电模拟考试系统-2025.html
```

任何现代浏览器（Windows / macOS / Linux / 手机）均可运行，所有题目、图片、程序全部内嵌在这一个文件中，数据保存在浏览器 localStorage，完全离线使用。

## 功能

- **全真模拟考试**：按真实考试规则随机抽题、限时、选项乱序
  - 2025 版：A 类 30 题 / 40 分钟 / 合格 24 题（题库 683 题）· B 类 50 题 / 60 分钟 / 合格 40 题（题库 1143 题）· C 类 90 题 / 100 分钟 / 合格 60 题（题库 1282 题）
  - 2017 版：A 类 30 题 / 40 分钟 / 合格 25 题（题库 361 题）· B 类 50 题 / 60 分钟 / 合格 40 题（题库 685 题）· C 类 80 题 / 90 分钟 / 合格 60 题（题库 1061 题）
- **多选题**（2025 版）：C 类等含多选题（252 题），需选中全部正确项方判对，练习中选满后自动判分
- **顺序练习**：按题号顺序逐题复习，即时判分并显示正确答案
- **随机练习**：随机顺序抽取 10/25/50/100/200/全部 题复习
- **错题本**：答错自动收录，支持回看（含正确答案与上次错选）、错题重考、连对 2 次自动移出、导出/导入 JSON
- **统计**：覆盖率、正确率、各类别掌握度、历史成绩单
- 考试中途刷新页面可恢复未交卷的会话

## 关于答案正确性

- **2017 版**：官方 TXT 题库中每题正确答案恒为 `[A]` 选项，展示时随机打乱选项顺序，判定始终指向原始正确选项；附图按 `[P]图片文件名` 严格对应，官方漏标的 `LK0938.jpg` 已在构建时补上关联。
- **2025 版**：答案由题目 `[T]` 字段给出（可多选 A–D），解析为索引数组后判定；附图按「附图标记.pdf 中 LK 标注 ↔ 题号 4 位后缀」一一对应，53 张图全部内嵌 base64。

两版均内置全量数据层校验（题量 / 规则 / 多选答案 / 图片 / 类别）与判分逻辑模拟，全部题目判定逐一通过。

## 开发

```
src/index.html      HTML 模板
src/styles.css      样式
src/app.js          前端逻辑（原生 JS，无框架、无外部依赖；支持单/多选判分）
tools/build.py      2017 版构建：解析 GBK TXT 题库 → 校验 → 内嵌 → 生成单文件 HTML
tools/build_2025.py 2025 版构建：解析 总题库/A|B|C类/附图标记.pdf → 校验 → 内嵌 → 生成 HTML
tools/e2e-test.js   Playwright 端到端冒烟测试（需 playwright + chromium）
tools/verify-answers.js   2017 版答案正确性校验：与官方题库源文件逐字段比对全部 1237 题，零依赖、无需浏览器
tools/_check_2025html.js  2025 版数据层校验：题量/规则/多选答案/图片/类别
tools/_sim_grade.js       2025 版判分逻辑全量模拟：任意选项组合 + 打乱下 isRight/correctText 判定正确
tools/_img_valid.js       校验内嵌 53 张附图 base64 为可解码 JPEG
tools/_serve2025.js       本地静态服务器，供内置浏览器预览 2025 HTML（file:// 受限）
database/           官方题库原始文件（勿改动）
```

重新构建：

```bash
python tools/build.py        # 2017 版
python tools/build_2025.py   # 2025 版
```

2025 版数据层校验与判分模拟：

```bash
node tools/_check_2025html.js
node tools/_sim_grade.js
node tools/_img_valid.js
```

## 题库版本说明

本程序内置两套 CRAC 题库：2017 版（v171031）与 2025 版（C 类改为 90 题并新增多选题）。备考最新考核时请以 2025 版为准，并以 CRAC 官方最新题库作为最终依据。
